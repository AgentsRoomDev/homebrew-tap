# AgentsRoom Homebrew tap

```sh
brew install --cask agentsroomdev/tap/agentsroom
```

[AgentsRoom](https://agentsroom.dev) is a desktop app to run and coordinate several AI coding agents (Claude Code, Codex, Antigravity and more) side by side.

This repository only holds the install recipe: it downloads the official, notarized app from `agentsroom.dev`. The app keeps itself up to date; the recipe follows each release automatically.
